DQL (Data Query Language, 데이터 질의어)
대표 명령어

SELECT — 데이터 조회 (사실상 DQL의 유일한 핵심 명령어)



DML (Data Manipulation Language, 데이터 조작어)
대표 명령어

INSERT — 새 데이터(행) 추가
UPDATE — 기존 데이터 수정
DELETE — 기존 데이터 삭제


DDL (Data Definition Language, 데이터 정의어)
대표 명령어

CREATE — 테이블·데이터베이스·인덱스·뷰 등 새 객체 생성
ALTER — 기존 테이블 구조(컬럼 추가/삭제/변경) 수정
DROP — 테이블·데이터베이스 자체를 삭제
TRUNCATE — 테이블의 모든 데이터를 비우되 구조는 유지
RENAME — 테이블이나 컬럼의 이름 변경
